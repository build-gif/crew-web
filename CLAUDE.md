# Crew of Builders

Crew of Builders is the official website for a curated community of founders, operators, and builders powered by **WE Heart Impact**. The platform connects people who are actively building companies — sharing what they ship, learning from each other, and accessing mentorship, capital, and opportunities.

## Rules

Rules are located in `.claude/rules/`:

| File | Content |
|---|---|
| [`architecture.md`](.claude/rules/architecture.md) | Stack, design decisions, what's out of scope |
| [`code-style.md`](.claude/rules/code-style.md) | Naming, imports, components, Tailwind, async |
| [`workflow.md`](.claude/rules/workflow.md) | Plan mode, commits, tests, code review |
| [`security.md`](.claude/rules/security.md) | Auth, env vars, Zod, cookies, rate limit |
| [`performance.md`](.claude/rules/performance.md) | Server components, Prisma, images, bundle |
| [`commands.md`](.claude/rules/commands.md) | Available commands and permissions |


- `/commit` — generates conventional commit message from diff
